# by-architect.github.io

The root of **https://by-architect.github.io**: a short page that lists the apps, and `app-ads.txt`.

AdMob reads `app-ads.txt` from the root of the developer website given on an app's Google Play page, to confirm which
ad accounts may sell ads in the app. Only the root of the domain counts, so it lives here and not in an app's own site.
Add a line when another app shows ads from a different AdMob account.

Each app's own site is a separate repository served below this address, such as
[hadith-web](https://github.com/by-architect/hadith-web) at https://by-architect.github.io/hadith-web/.
