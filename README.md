# by-architect.github.io

The root of **https://by-architect.github.io**: a short page that lists the apps, `app-ads.txt`, and the privacy
policies of apps whose own repositories are private.

AdMob reads `app-ads.txt` from the root of the developer website given on an app's Google Play page, to confirm which
ad accounts may sell ads in the app. Only the root of the domain counts, so it lives here and not in an app's own site.
Add a line when another app shows ads from a different AdMob account.

[hadith/PRIVACY.md](hadith/PRIVACY.md) is Hadith Library's privacy policy, the one Google Play links to. It is a copy
of `PRIVACY.md` in the app's private repository, published here for everyone to read; do not edit it here.
